## 实现计划

### 1. 问题分析

用户要求实现以下功能：
- 文章资讯顶部换成一个轮播图
- 在文章管理模块的“分类管理”旁边加一个轮播图管理
- 管理员可以上传轮播图，存储是cos对象存储

### 2. 实现方案

#### 2.1 后端实现

1. **创建轮播图实体类**：
   - 创建 `Banner` 实体类，包含 id、title、imageUrl、linkUrl、sortOrder、status 等字段
   - 使用 `@TableName` 注解指定表名
   - 使用 `@TableId` 注解指定主键
   - 使用 `@TableLogic` 注解实现逻辑删除

2. **创建轮播图Mapper**：
   - 继承 `BaseMapper<Banner>` 接口
   - 提供基本的CRUD方法

3. **创建轮播图Service**：
   - 继承 `IService<Banner>` 接口
   - 实现轮播图的CRUD操作
   - 实现获取轮播图列表的方法

4. **创建轮播图Controller**：
   - 提供轮播图的CRUD接口
   - 提供上传轮播图的接口，使用COS存储
   - 提供获取轮播图列表的接口

5. **集成COS对象存储**：
   - 使用已有的 `CosUtils` 工具类
   - 上传轮播图到COS，返回COS URL

#### 2.2 前端实现

1. **修改ArticlePage.vue**：
   - 将顶部banner换成轮播图
   - 使用Ant Design Vue的 `a-carousel` 组件
   - 调用后端接口获取轮播图列表
   - 显示轮播图

2. **修改ArticleManagePage.vue**：
   - 在操作栏添加轮播图管理按钮
   - 点击按钮跳转到轮播图管理页面

3. **创建轮播图管理页面**：
   - 创建 `BannerManagePage.vue` 页面
   - 实现轮播图的列表展示
   - 实现轮播图的添加、编辑、删除功能
   - 实现轮播图的上传功能，使用COS存储

### 8. 数据库设计

```sql
CREATE TABLE `banner` (
  `id` bigint NOT NULL AUTO_INCREMENT COMMENT '主键',
  `title` varchar(255) DEFAULT NULL COMMENT '标题',
  `image_url` varchar(512) DEFAULT NULL COMMENT '图片URL',
  `link_url` varchar(512) DEFAULT NULL COMMENT '链接URL',
  `sort_order` int DEFAULT '0' COMMENT '排序',
  `status` tinyint DEFAULT '1' COMMENT '状态：0-禁用，1-启用',
  `create_time` datetime DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time` datetime DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  `is_delete` tinyint DEFAULT '0' COMMENT '逻辑删除：0-未删除，1-已删除',
  PRIMARY KEY (`id`),
  KEY `idx_sort_order` (`sort_order`),
  KEY `idx_status` (`status`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='轮播图表';
```
