# 修复 LeftOne 组件显示前五人群百分比的问题

## 问题分析
1. 用户反映 LeftOne 组件没有正确显示前五人群百分比
2. 但当前 LeftOne 组件实现的是用户增长趋势折线图，使用的是 `getUserGrowth` API
3. 用户提供的接口响应是 `getTargetTopFive` API 的返回结果，包含前五人群分布数据
4. 实际上 LeftTwo 组件已经在使用 `getTargetTopFive` API 实现饼图显示人群分布
5. 可能存在组件功能分配错误，需要将 LeftOne 组件修改为显示前五人群百分比

## 修复方案
将 LeftOne 组件修改为显示前五人群百分比，具体步骤如下：

1. 修改 LeftOne.vue 组件：
   - 将折线图改为饼图或环形图
   - 替换 API 调用，从 `getUserGrowth` 改为 `getTargetTopFive`
   - 调整数据处理逻辑，适配新的 API 响应格式
   - 确保图表能正确显示百分比

2. 保持 LeftTwo 组件不变（如果需要两个相同的图表），或者根据实际需求调整

## 预期效果
LeftOne 组件将正确显示前五人群的百分比分布，使用用户提供的接口数据。
