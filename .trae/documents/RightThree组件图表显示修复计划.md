# RightThree组件图表显示修复计划

## 问题分析

图表没有显示的可能原因：
1. 图表初始化时机问题：组件挂载时`chartRef.value`可能还未完全渲染
2. 图表实例有效性检查缺失：在调用`chartInstance.setOption()`时未检查实例是否有效
3. 缺少窗口大小变化监听：窗口大小变化时图表未自动调整
4. 异步数据获取与图表初始化的时序问题

## 修复方案

### 1. 确保图表容器已渲染
- 在`initChart`函数中添加对`chartRef.value`的检查
- 确保只有当容器存在时才初始化图表

### 2. 添加图表实例有效性检查
- 在`updateChart`函数中添加对`chartInstance`的检查
- 在`fetchData`函数中添加对`chartInstance`的检查
- 确保只有当图表实例有效时才调用相关方法

### 3. 添加窗口大小变化监听
- 在组件挂载时添加`resize`事件监听
- 实现图表自适应大小
- 在组件卸载时移除事件监听

### 4. 优化数据初始化逻辑
- 确保初始状态下图表有默认数据显示
- 优化异步数据获取与图表更新的时序

## 代码修改点

1. **initChart函数**：添加容器存在性检查
2. **updateChart函数**：添加图表实例有效性检查
3. **onMounted钩子**：添加窗口大小变化监听
4. **onBeforeUnmount钩子**：添加事件监听移除
5. **fetchData函数**：优化数据处理逻辑

## 预期效果

- 组件挂载后图表能正常显示
- 异步数据获取后图表能正确更新
- 窗口大小变化时图表能自适应调整
- 图表实例能正确销毁，避免内存泄漏
