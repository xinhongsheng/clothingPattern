## 问题分析
当前文章标签处理存在以下问题：
- 后端 ArticleAddRequest 已使用 List<String> tag 接收前端请求，但 Article 实体类仍使用 String tags 存储
- 前端使用 a-input 输入标签，用逗号分隔，用户体验不佳
- 缺少预设标签列表，用户需要手动输入所有标签

## 修复计划

### 1. 后端修改

#### 1.1 修改 ArticleServiceImpl.java
- 在 `addArticle` 方法中，添加标签转换逻辑，将 List<String> 转换为 JSON 字符串存储
- 在 `updateArticle` 方法中，添加标签转换逻辑，将 List<String> 转换为 JSON 字符串存储

#### 1.2 修改 ArticleAddRequest.java
- 将 `tag` 字段名改为 `tags`，保持与实体类一致

#### 1.3 修改 Article.java
- 确保 `tags` 字段用于存储 JSON 字符串

### 2. 前端修改

#### 2.1 修改 ArticleEditPage.vue
- 将标签输入框从 `a-input` 改为 `a-select` 组件，支持多选
- 添加预设标签列表
- 修改 `formData.tags` 的类型，从 `string` 改为 `string[]`
- 修改 `handlePublish` 和 `handleSaveDraft` 方法，确保正确处理标签数组

#### 2.2 修改 typings.d.ts
- 更新 `ArticleAddRequest` 类型，将 `tags` 字段类型从 `string` 改为 `string[]`
- 更新 `Article` 和 `ArticleVO` 类型，将 `tags` 字段类型从 `string` 改为 `string[]`

### 3. 测试修复效果
- 运行后端项目
- 运行前端项目
- 测试文章发布、编辑功能，确保标签能正确保存和显示

## 预期结果
- 前端使用多选下拉框选择标签，支持预设标签
- 后端将标签数组转换为 JSON 字符串存储
- 文章详情页能正确显示标签
- 所有文章相关功能正常工作

## 技术细节
- 后端使用 FastJSON 将 List<String> 转换为 JSON 字符串
- 前端使用 Ant Design Vue 的 a-select 组件实现多选
- 预设标签列表可在前端配置，或从后端获取

这个修复将提升用户体验，让用户可以方便地选择预设标签，同时确保标签数据能正确存储和显示。
