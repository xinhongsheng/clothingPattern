## 修复计划

### 1. 问题分析

当前浏览量功能存在以下问题：
- `incrementViewCount` 方法将阅读量增加到 Redis 中，但没有同步到数据库
- `selectArticleDetail` 方法直接从数据库中查询阅读量，而不是从 Redis 中获取
- 没有定时任务将 Redis 中的阅读量同步到数据库

### 2. 修复方案

直接修改 `incrementViewCount` 方法，改为直接调用数据库的 `incrementViewCount` 方法，而不是使用 Redis 异步更新。
