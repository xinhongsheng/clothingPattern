# 评论功能快速开始指南

## 🚀 5分钟快速开始

### 步骤1：初始化数据库（1分钟）

执行数据库初始化脚本：

```bash
mysql -u root -p xhs_clothingPattern_db < 评论功能数据库初始化.sql
```

或者在 MySQL 客户端中执行：

```sql
-- 创建评论表
CREATE TABLE IF NOT EXISTS `comment` (
  `id` bigint NOT NULL COMMENT '评论ID',
  `userId` bigint NOT NULL COMMENT '评论用户ID',
  `patternId` bigint NOT NULL COMMENT '被评论图案ID',
  `content` varchar(500) NOT NULL COMMENT '评论内容',
  `parentId` bigint DEFAULT NULL COMMENT '父评论ID',
  `createTime` datetime DEFAULT CURRENT_TIMESTAMP COMMENT '评论时间',
  `updateTime` datetime DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  `isDelete` tinyint DEFAULT '0' COMMENT '逻辑删除',
  `likeCount` int DEFAULT '0' COMMENT '点赞数',
  `replyCount` int DEFAULT '0' COMMENT '回复数',
  `topStatus` tinyint DEFAULT '0' COMMENT '置顶状态',
  `auditStatus` varchar(20) DEFAULT 'PENDING' COMMENT '审核状态',
  PRIMARY KEY (`id`),
  KEY `idx_patternId` (`patternId`),
  KEY `idx_userId` (`userId`),
  KEY `idx_parentId` (`parentId`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 创建评论点赞表
CREATE TABLE IF NOT EXISTS `comment_like` (
  `id` bigint NOT NULL COMMENT '评论点赞ID',
  `userId` bigint NOT NULL COMMENT '点赞用户ID',
  `commentId` bigint NOT NULL COMMENT '被点赞评论ID',
  `patternId` bigint NOT NULL COMMENT '图案ID',
  `createTime` datetime DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `isDelete` tinyint DEFAULT '0' COMMENT '逻辑删除',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_user_comment` (`userId`,`commentId`),
  KEY `idx_commentId` (`commentId`),
  KEY `idx_patternId` (`patternId`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

## 📋 核心接口说明

### 1. 添加评论
```
POST /api/comment/add
Content-Type: application/json

{
  "patternId": 123456,
  "content": "评论内容",
  "parentId": null  // 回复时填写父评论ID
}
```

### 2. 查询评论列表
```
POST /api/comment/list
Content-Type: application/json

{
  "patternId": 123456,
  "current": 1,
  "pageSize": 10
}
```

### 3. 点赞评论
```
POST /api/comment/like/{commentId}
```

### 4. 删除评论
```
POST /api/comment/delete/{commentId}
```

### 5. 获取统计信息
```
GET /api/comment/statistics/{patternId}
```

## 🎯 前端集成示例

### Vue3 + TypeScript

```typescript
// api/comment.ts
import { request } from '@/utils/request'

export async function addComment(data: {
  patternId: number
  content: string
  parentId?: number
}) {
  return request({
    url: '/api/comment/add',
    method: 'POST',
    data
  })
}

export async function getCommentList(data: {
  patternId: number
  current: number
  pageSize: number
}) {
  return request({
    url: '/api/comment/list',
    method: 'POST',
    data
  })
}
```

```vue
<!-- CommentSection.vue -->
<template>
  <div class="comment-section">
    <!-- 添加评论 -->
    <a-textarea
      v-model:value="content"
      placeholder="写下你的评论..."
      :rows="3"
    />
    <a-button type="primary" @click="handleAdd">
      发表评论
    </a-button>

    <!-- 评论列表 -->
    <div v-for="comment in comments" :key="comment.id">
      <div>{{ comment.userName }}: {{ comment.content }}</div>
      <a-button @click="handleLike(comment.id)">
        点赞 {{ comment.likeCount }}
      </a-button>
    </div>
  </div>
</template>

<script setup lang="ts">
import { ref, onMounted } from 'vue'
import { addComment, getCommentList } from '@/api/comment'

const props = defineProps<{ patternId: number }>()
const content = ref('')
const comments = ref([])

const handleAdd = async () => {
  await addComment({
    patternId: props.patternId,
    content: content.value
  })
  content.value = ''
  loadComments()
}

const loadComments = async () => {
  const res = await getCommentList({
    patternId: props.patternId,
    current: 1,
    pageSize: 10
  })
  comments.value = res.data.data.records
}

onMounted(loadComments)
</script>
```

## ❓ 常见问题

### Q1: 评论提交后没有显示？
A: 检查评论的 `auditStatus` 是否为 `APPROVED`。默认是自动通过的，如果修改了代码设置为 `PENDING`，需要先审核通过。

### Q2: 点赞功能不生效？
A: 确保用户已登录，检查 Session 或 Token 是否正确传递。

### Q3: 查询评论列表时报错？
A: 检查 `patternId` 是否存在，确保图案已创建且未被删除。

### Q4: 如何修改评论内容长度限制？
A: 修改 `CommentAddRequest` 中的 `@Size` 注解，同时修改数据库表的 `content` 字段长度。
