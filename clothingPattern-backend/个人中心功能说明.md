# 个人中心功能说明

## 📋 功能概述

个人中心页面包含以下功能：
1. **个人信息展示与修改** - 查看和更新用户昵称、头像、个人简介
2. **我的收藏** - 查看用户收藏的所有文章

## 🔧 后端实现

### 1. 新增接口

#### UserController

**接口**: `POST /user/update/my`
**描述**: 更新个人信息
**请求体**:
```json
{
  "userName": "用户昵称",
  "userAvatar": "头像URL",
  "userProfile": "个人简介"
}
```
**响应**:
```json
{
  "code": 0,
  "data": true,
  "message": "ok"
}
```

#### ArticleController

**接口**: `GET /article/my/collect`
**描述**: 获取我的收藏文章列表
**响应**:
```json
{
  "code": 0,
  "data": [
    {
      "id": 1,
      "title": "文章标题",
      "coverImage": "封面图URL",
      "summary": "文章摘要",
      "viewCount": 100,
      "likeCount": 50,
      "collectCount": 30,
      "collected": true,
      "liked": false
    }
  ]
}
```

### 2. 新增 DTO

**文件**: `UserUpdateMyRequest.java`

```java
@Data
public class UserUpdateMyRequest implements Serializable {
    private String userName;      // 用户昵称
    private String userAvatar;    // 用户头像
    private String userProfile;   // 个人简介
}
```

### 3. Service 实现

**ArticleServiceImpl.getMyCollectArticles()**

逻辑流程：
1. 查询用户收藏记录（`article_collect` 表）
2. 获取文章ID列表
3. 查询文章详情
4. 转换为VO并设置用户交互状态
5. 返回文章列表

## 🎨 前端实现

### 1. 页面结构

**文件**: `UserProfilePage.vue`

使用 Ant Design Vue 的 Tabs 组件，包含两个标签页：

#### Tab 1: 个人信息
- **头像上传**: 支持本地预览（Base64）
- **昵称输入**: 最多20个字符
- **账号显示**: 只读，不可修改
- **个人简介**: 多行文本，最多200字符，显示字数统计
- **操作按钮**: 保存修改、重置

#### Tab 2: 我的收藏
- **文章卡片**: 网格布局，响应式
- **卡片内容**: 封面图、标题、摘要、统计数据
- **交互**: 点击卡片跳转到文章详情

### 2. 前端API

**文件**: `userController.ts`

```typescript
// 更新个人信息
export async function updateMyUser(
  body: API.UserUpdateMyRequest,
  options?: { [key: string]: any }
)
```

**文件**: `articleController.ts`

```typescript
// 获取我的收藏文章列表
export async function getMyCollectArticles(
  options?: { [key: string]: any }
)
```

### 3. 路由配置

**路径**: `/user/profile`
**名称**: 个人中心
**组件**: `UserProfilePage.vue`

## 🎯 使用方式

### 访问个人中心

1. **从导航栏进入**:
   - 点击用户头像下拉菜单
   - 选择"个人中心"

2. **直接访问URL**:
   ```
   http://localhost:5173/user/profile
   ```

### 修改个人信息

1. 进入"个人信息"标签页
2. 点击"更换头像"上传新头像（可选）
3. 修改昵称和个人简介
4. 点击"保存修改"按钮
5. 等待保存成功提示

### 查看收藏

1. 进入"我的收藏"标签页
2. 浏览收藏的文章列表
3. 点击任意文章卡片查看详情

## 🔐 权限控制

### 登录验证

- 所有接口都需要登录
- 未登录用户访问会返回 401 错误
- 前端会自动跳转到登录页面

### 数据隔离

- 每个用户只能看到自己的收藏
- 只能修改自己的个人信息
- 后端通过 Session 获取当前登录用户

## 📊 数据流程

### 个人信息更新流程

```
用户修改表单
    ↓
点击保存按钮
    ↓
调用 updateMyUser API
    ↓
后端验证登录状态
    ↓
更新数据库
    ↓
返回成功响应
    ↓
刷新用户 Store
    ↓
显示成功提示
```

### 收藏列表加载流程

```
进入收藏标签页
    ↓

    ↓
后端查询 article_collect 表
    ↓
获取文章ID列表
    ↓
查询文章详情
    ↓
设置用户交互状态
    ↓
返回文章列表
    ↓
前端渲染卡片
```
