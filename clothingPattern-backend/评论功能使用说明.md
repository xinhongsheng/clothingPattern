# 评论功能使用说明

## 功能概述

实现了完整的图案评论功能，包括：
- ✅ 添加评论（主评论和回复）
- ✅ 查询评论列表（分页）
- ✅ 删除评论
- ✅ 评论点赞/取消点赞
- ✅ 评论统计信息
- ✅ 评论审核状态管理

## 数据库表结构

### comment 表（评论表）
```sql
CREATE TABLE `comment` (
  `id` bigint NOT NULL COMMENT '评论ID',
  `userId` bigint NOT NULL COMMENT '评论用户ID',
  `patternId` bigint NOT NULL COMMENT '被评论图案ID',
  `content` varchar(500) NOT NULL COMMENT '评论内容',
  `parentId` bigint DEFAULT NULL COMMENT '父评论ID',
  `createTime` datetime DEFAULT CURRENT_TIMESTAMP COMMENT '评论时间',
  `updateTime` datetime DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  `isDelete` tinyint DEFAULT '0' COMMENT '逻辑删除',
  `likeCount` int DEFAULT '0' COMMENT '点赞数',
  `replyCount` int DEFAULT '0' COMMENT '回复数',
  `topStatus` tinyint DEFAULT '0' COMMENT '置顶状态',
  `auditStatus` varchar(20) DEFAULT 'PENDING' COMMENT '审核状态',
  PRIMARY KEY (`id`),
  KEY `idx_patternId` (`patternId`),
  KEY `idx_userId` (`userId`),
  KEY `idx_parentId` (`parentId`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### comment_like 表（评论点赞表）
```sql
CREATE TABLE `comment_like` (
  `id` bigint NOT NULL COMMENT '评论点赞ID',
  `userId` bigint NOT NULL COMMENT '点赞用户ID',
  `commentId` bigint NOT NULL COMMENT '被点赞评论ID',
  `patternId` bigint NOT NULL COMMENT '图案ID（冗余字段）',
  `createTime` datetime DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `isDelete` tinyint DEFAULT '0' COMMENT '逻辑删除',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_user_comment` (`userId`,`commentId`),
  KEY `idx_commentId` (`commentId`),
  KEY `idx_patternId` (`patternId`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

**请求参数**:

```json
  "parentId": null  // 主评论时为null，回复评论时填写父评论ID
```

### 3. 删除评论
**接口**: `POST /api/comment/delete/{commentId}`

**路径参数**: `commentId` - 评论ID

**响应**:
```json
{
  "code": 0,
  "data": true,
  "message": "ok"
```

**接口**: `POST /api/comment/like/{commentId}`

**路径参数**: `commentId` - 评论ID

**响应**:
```json
{
  "code": 0,
  "data": true,  // true表示已点赞，false表示已取消点赞
  "message": "ok"
}
```

**接口**: `GET /api/comment/statistics/{patternId}`

**路径参数**: `patternId` - 图案ID

```json

  "code": 0,

    "mainComments": 30,     // 主评论数（不包括回复）
```

## 核心功能说明

### 1. 评论层级结构
- **主评论**: `parentId` 为 `null` 的评论
- **回复评论**: `parentId` 不为 `null` 的评论，指向父评论
- 查询评论列表时，自动加载每个主评论的前3条回复

### 2. 审核机制
- 默认评论状态为 `APPROVED`（已通过）
- 如需人工审核，可在 `addComment` 方法中将 `auditStatus` 设置为 `PENDING`
- 审核状态：
  - `PENDING`: 待审核
  - `APPROVED`: 已通过
  - `REJECTED`: 已拒绝

### 3. 点赞功能
- 支持对评论点赞/取消点赞
- 使用逻辑删除实现点赞状态切换
- 自动更新评论的点赞数

### 4. 权限控制
- 添加评论需要登录
- 只能删除自己的评论
- 点赞需要登录
- 查询评论列表不需要登录（但会影响点赞状态显示）

### 5. 数据完整性
- 添加评论时验证图案是否存在且已审核
- 回复评论时验证父评论是否存在且属于同一图案
- 删除评论时自动更新父评论的回复数

## 使用示例

### 前端调用示例（Vue3 + TypeScript）

```typescript
import { request } from '@/utils/request'

// 1. 添加评论
export async function addComment(data: {
  patternId: number

}) {
  return request({
    url: '/api/comment/add',
    method: 'POST',

  })

// 2. 查询评论列表
export async function getCommentList(data: {
  patternId: number
  current: number
  pageSize: number
}) {
  return request({
    url: '/api/comment/list',
    method: 'POST',
    data
  })
}

// 3. 点赞评论
export async function toggleCommentLike(commentId: number) {
  return request({
    url: `/api/comment/like/${commentId}`,
    method: 'POST'
  })
}

// 4. 删除评论
export async function deleteComment(commentId: number) {
  return request({
    url: `/api/comment/delete/${commentId}`,
    method: 'POST'
  })
}

// 5. 获取评论统计
export async function getCommentStatistics(patternId: number) {
  return request({
    url: `/api/comment/statistics/${patternId}`,
    method: 'GET'
  })
}
```

### 前端组件示例

```vue
<template>
  <div class="comment-section">
    <!-- 评论统计 -->
    <div class="comment-stats">
      <span>{{ statistics.totalComments }} 条评论</span>
      <span>{{ statistics.totalLikes }} 个赞</span>
    </div>

    <!-- 添加评论 -->
    <div class="add-comment">
      <a-textarea
        v-model:value="commentContent"
        placeholder="写下你的评论..."
        :rows="3"
      />
      <a-button type="primary" @click="handleAddComment">
        发表评论
      </a-button>
    </div>

    <!-- 评论列表 -->
    <div class="comment-list">
      <div v-for="comment in comments" :key="comment.id" class="comment-item">
        <div class="comment-header">
          <a-avatar :src="comment.userAvatar" />
          <span class="user-name">{{ comment.userName }}</span>
          <span class="time">{{ formatTime(comment.createTime) }}</span>
        </div>
        <div class="comment-content">{{ comment.content }}</div>
        <div class="comment-actions">
          <a-button type="text" @click="handleLike(comment)">
            <HeartOutlined v-if="!comment.liked" />
            <HeartFilled v-else style="color: red" />
            {{ comment.likeCount }}
          </a-button>
          <a-button type="text" @click="handleReply(comment)">
            回复 {{ comment.replyCount }}
          </a-button>
          <a-button
            v-if="comment.userId === currentUserId"
            type="text"
            danger
            @click="handleDelete(comment.id)"
          >
            删除
          </a-button>
        </div>

        <!-- 回复列表 -->
        <div v-if="comment.children && comment.children.length > 0" class="reply-list">
          <div v-for="reply in comment.children" :key="reply.id" class="reply-item">
            <!-- 回复内容 -->
          </div>
        </div>
      </div>
    </div>

    <!-- 分页 -->
    <a-pagination
      v-model:current="current"
      v-model:pageSize="pageSize"
      :total="total"
      @change="loadComments"
    />
  </div>
</template>

<script setup lang="ts">
import { ref, onMounted } from 'vue'
import { message } from 'ant-design-vue'
import {
  addComment,
  getCommentList,
  toggleCommentLike,
  deleteComment,
  getCommentStatistics
} from '@/api/comment'

const props = defineProps<{
  patternId: number
}>()

const comments = ref([])
const statistics = ref({})
const commentContent = ref('')
const current = ref(1)
const pageSize = ref(10)
const total = ref(0)

// 加载评论列表
const loadComments = async () => {
  const res = await getCommentList({
    patternId: props.patternId,
    current: current.value,
    pageSize: pageSize.value
  })
  if (res.data.code === 0) {
    comments.value = res.data.data.records
    total.value = res.data.data.total
  }
}

// 加载统计信息
const loadStatistics = async () => {
  const res = await getCommentStatistics(props.patternId)
  if (res.data.code === 0) {
    statistics.value = res.data.data
  }
}

// 添加评论
const handleAddComment = async () => {
  if (!commentContent.value.trim()) {
    message.warning('请输入评论内容')
    return
  }
  
  const res = await addComment({
    patternId: props.patternId,
    content: commentContent.value
  })
  
  if (res.data.code === 0) {
    message.success('评论成功')
    commentContent.value = ''
    loadComments()
    loadStatistics()
  }
}

// 点赞
const handleLike = async (comment: any) => {
  const res = await toggleCommentLike(comment.id)
  if (res.data.code === 0) {
    comment.liked = res.data.data
    comment.likeCount += res.data.data ? 1 : -1
    message.success(res.data.data ? '点赞成功' : '已取消点赞')
  }
}

// 删除
const handleDelete = async (commentId: number) => {
  const res = await deleteComment(commentId)
  if (res.data.code === 0) {
    message.success('删除成功')
    loadComments()
    loadStatistics()
  }
}

onMounted(() => {
  loadComments()
  loadStatistics()
})
</script>
```

## 注意事项

1. **性能优化**
   - 评论列表查询时只返回主评论的前3条回复
   - 使用批量查询优化点赞状态的获取
   - 建议对评论表添加适当的索引

2. **安全性**
   - 评论内容长度限制为500字
   - 只能删除自己的评论
   - 需要验证图案是否存在且已审核

3. **扩展性**
   - 可以添加评论举报功能
   - 可以添加评论编辑功能
   - 可以添加评论置顶功能（已预留字段）
   - 可以添加评论审核功能（已预留字段）

4. **数据一致性**
   - 使用事务保证数据一致性
   - 删除评论时自动更新父评论的回复数
   - 点赞时自动更新评论的点赞数
