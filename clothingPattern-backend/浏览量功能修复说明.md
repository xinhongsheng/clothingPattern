# 浏览量功能修复说明

## 🐛 问题描述

文章被点击查看后，浏览量（viewCount）没有增加。

## 🔍 问题原因

1. **浏览量只写入Redis，未同步到数据库**
   - `ArticleServiceImpl.incrementViewCount()` 方法只是将浏览量增加到Redis中
   - 没有定时任务将Redis中的浏览量同步到MySQL数据库

2. **缺少批量更新方法**
   - 原有的 `ArticleMapper.incrementViewCount()` 每次只能+1
   - 如果Redis中累计了多次浏览，需要多次调用，效率低下

## ✅ 修复方案

### 1. 添加批量更新浏览量的Mapper方法

**文件**: `ArticleMapper.java`

**新增方法**:
```java
/**
 * 批量增加阅读量
 */
@Update("UPDATE article SET viewCount = viewCount + #{increment} WHERE id = #{id}")
int incrementViewCountBatch(@Param("id") Long id, @Param("increment") int increment);
```

### 2. 修改同步任务，添加浏览量同步功能

**文件**: `LikeSyncTask.java`

**修改内容**:

1. **添加依赖注入**:
```java
@Autowired
private StringRedisTemplate stringRedisTemplate;

@Autowired
private ArticleMapper articleMapper;

private static final String ARTICLE_VIEW_KEY_PREFIX = "article:view:";
```

2. **在定时任务中添加浏览量同步**:
```java
@Scheduled(fixedRate = 1 * 60 * 1000) // 每1分钟执行一次
@Transactional
public void syncLikeDataToMySQL() {
    log.info("开始同步点赞数据到MySQL...");

    // 1. 同步点赞计数
    syncLikeCounts();

    // 2. 同步用户点赞关系
    syncUserLikeRelations();

    // 3. 同步文章浏览量 ✅ 新增
    syncArticleViewCounts();

    log.info("点赞数据同步完成");
}
```

3. **新增浏览量同步方法**:
```java
/**
 * 同步文章浏览量到数据库
 */
private void syncArticleViewCounts() {
    try {
        // 获取所有浏览量key
        Set<String> viewKeys = stringRedisTemplate.keys(ARTICLE_VIEW_KEY_PREFIX + "*");
        if (viewKeys == null || viewKeys.isEmpty()) {
            return;
        }

        int syncCount = 0;
        int totalViews = 0;
        
        for (String viewKey : viewKeys) {
            // 提取文章ID
            String articleIdStr = viewKey.substring(ARTICLE_VIEW_KEY_PREFIX.length());
            Long articleId = Long.parseLong(articleIdStr);

            // 获取Redis中累计的浏览次数
            String viewCountStr = stringRedisTemplate.opsForValue().get(viewKey);
            if (viewCountStr != null && !viewCountStr.isEmpty()) {
                int incrementCount = Integer.parseInt(viewCountStr);
                
                if (incrementCount > 0) {
                    // 批量增加浏览量
                    articleMapper.incrementViewCountBatch(articleId, incrementCount);
                    
                    // 删除Redis中的key
                    stringRedisTemplate.delete(viewKey);
                    
                    syncCount++;
                    totalViews += incrementCount;
                }
            }
        }

        if (syncCount > 0) {
            log.info("成功同步 {} 篇文章的浏览量，共 {} 次浏览", syncCount, totalViews);
        }
    } catch (Exception e) {
        log.error("同步文章浏览量时发生异常", e);
    }
}
```

## 🔄 工作流程

### 用户查看文章时：

1. **前端请求**: 用户点击文章 → 调用 `GET /article/{id}`
2. **后端处理**: 
   - `ArticleController.getArticleDetail()` 接收请求
   - `ArticleServiceImpl.getArticleDetail()` 查询文章详情
   - `incrementViewCount()` 将浏览量+1写入Redis
   - Redis Key: `article:view:{articleId}`, Value: 累计浏览次数
3. **返回数据**: 返回文章详情给前端

### 定时同步到数据库：

1. **定时任务**: 每1分钟执行一次 `syncLikeDataToMySQL()`
2. **同步浏览量**: 
   - 扫描所有 `article:view:*` 的Redis key
   - 读取每个key的值（累计浏览次数）
   - 批量更新数据库：`UPDATE article SET viewCount = viewCount + 累计次数`
   - 删除已同步的Redis key
3. **日志记录**: 记录同步的文章数和总浏览次数

## 📊 数据流示例

### 场景：文章ID=1被浏览5次

**时间线**:

| 时间 | 操作 | Redis状态 | 数据库状态 |
|------|------|-----------|-----------|
| 00:00 | 初始状态 | - | viewCount = 100 |
| 00:01 | 用户A查看 | article:view:1 = 1 | viewCount = 100 |
| 00:02 | 用户B查看 | article:view:1 = 2 | viewCount = 100 |
| 00:03 | 用户C查看 | article:view:1 = 3 | viewCount = 100 |
| 00:04 | 用户D查看 | article:view:1 = 4 | viewCount = 100 |
| 00:05 | 用户E查看 | article:view:1 = 5 | viewCount = 100 |
| 01:00 | 定时同步 | article:view:1 删除 | viewCount = 105 ✅ |

## 🎯 优势

1. **高性能**: 
   - 浏览量写入Redis，速度快
   - 批量同步到数据库，减少数据库压力

2. **数据一致性**: 
   - 定时同步保证最终一致性
   - 即使Redis宕机，最多丢失1分钟的数据

3. **可扩展性**: 
   - 可以调整同步频率（修改 `fixedRate` 参数）
   - 可以添加更多统计指标的同步

## 📝 配置说明

### 调整同步频率

在 `LikeSyncTask.java` 中修改：

```java
// 当前配置：每1分钟同步一次（测试用）
@Scheduled(fixedRate = 1 * 60 * 1000)

// 生产环境建议：每5分钟同步一次
@Scheduled(fixedRate = 5 * 60 * 1000)
```

### Redis Key命名规范

- 浏览量: `article:view:{articleId}`
- 点赞状态: `article:like:{articleId}`
- 点赞计数: `article:like:count:{articleId}`

## ⚠️ 注意事项

1. **Redis持久化**: 建议开启Redis的AOF持久化，防止数据丢失
2. **定时任务冲突**: 如果有多个服务实例，建议使用分布式锁避免重复同步
3. **数据库字段**: 确保 `viewCount` 字段类型为 `INT` 且有默认值0

## 🔧 故障排查

### 浏览量仍然不增加？

1. **检查Redis连接**:
```bash
redis-cli ping
# 应该返回 PONG
```

2. **检查定时任务是否执行**:
查看日志中是否有 "开始同步点赞数据到MySQL..." 的日志

3. **检查Redis中的数据**:
```bash
redis-cli
> KEYS article:view:*
> GET article:view:1
```

4. **检查数据库字段映射**:
确保 `application.yml` 中 `map-underscore-to-camel-case: false`
因为数据库字段是 `viewCount`（驼峰），不是 `view_count`（下划线）
