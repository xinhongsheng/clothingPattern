# 导航菜单集成说明

## 📌 如何在导航菜单中添加"资讯中心"入口

如果你的项目有导航栏（如顶部菜单、侧边栏等），需要添加文章资讯的入口。

### 方法一：顶部导航栏

如果有类似这样的导航栏组件：

```vue
<template>
  <div class="navbar">
    <a-menu mode="horizontal">
      <a-menu-item key="home" @click="goTo('/')">
        首页
      </a-menu-item>
      <a-menu-item key="pattern" @click="goTo('/patternGeneration')">
        智能创作
      </a-menu-item>
      <a-menu-item key="ai" @click="goTo('/ai')">
        AI问答
      </a-menu-item>
      <!-- 添加文章资讯入口 -->
      <a-menu-item key="article" @click="goTo('/article')">
        📰 资讯中心
      </a-menu-item>
      <a-menu-item key="myIdea" @click="goTo('/my_idea')">
        我的创意
      </a-menu-item>
    </a-menu>
  </div>
</template>

<script setup lang="ts">
import { useRouter } from 'vue-router'

const router = useRouter()

const goTo = (path: string) => {
  router.push(path)
}
</script>
```

### 方法二：侧边栏

如果有侧边栏菜单：

```vue
<template>
  <a-layout-sider>
    <a-menu mode="inline">
      <a-menu-item key="home" @click="goTo('/')">
        <HomeOutlined />
        <span>首页</span>
      </a-menu-item>
      <!-- 添加文章资讯入口 -->
      <a-menu-item key="article" @click="goTo('/article')">
        <ReadOutlined />
        <span>资讯中心</span>
      </a-menu-item>
    </a-menu>
  </a-layout-sider>
</template>
```

### 方法三：首页卡片入口

在首页添加一个卡片：

```vue
<template>
  <div class="home-page">
    <a-row :gutter="16">
      <!-- 其他功能卡片 -->
      
      <!-- 文章资讯卡片 -->
      <a-col :span="6">
        <a-card hoverable @click="goTo('/article')">
          <template #cover>
            <div class="card-cover">
              <ReadOutlined style="font-size: 48px; color: #1890ff;" />
            </div>
          </template>
          <a-card-meta
            title="资讯中心"
            description="最新的时尚资讯和穿搭指南"
          />
        </a-card>
      </a-col>
    </a-row>
  </div>
</template>

<script setup lang="ts">
import { useRouter } from 'vue-router'
import { ReadOutlined } from '@ant-design/icons-vue'

const router = useRouter()

const goTo = (path: string) => {
  router.push(path)
}
</script>

<style scoped>
.card-cover {
  display: flex;
  justify-content: center;
  align-items: center;
  height: 160px;
  background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
}
</style>
```

### 方法四：底部导航（移动端）

如果有移动端底部导航：

```vue
<template>
  <div class="bottom-nav">
    <a-tabs v-model:activeKey="activeTab" @change="handleTabChange">
      <a-tab-pane key="home" tab="首页">
        <HomeOutlined />
      </a-tab-pane>
      <a-tab-pane key="article" tab="资讯">
        <ReadOutlined />
      </a-tab-pane>
      <a-tab-pane key="pattern" tab="创作">
        <AppstoreOutlined />
      </a-tab-pane>
      <a-tab-pane key="mine" tab="我的">
        <UserOutlined />
      </a-tab-pane>
    </a-tabs>
  </div>
</template>

<script setup lang="ts">
import { ref } from 'vue'
import { useRouter, useRoute } from 'vue-router'

const router = useRouter()
const route = useRoute()

const activeTab = ref('home')

const handleTabChange = (key: string) => {
  const routeMap: Record<string, string> = {
    home: '/',
    article: '/article',
    pattern: '/patternGeneration',
    mine: '/my_idea'
  }
  router.push(routeMap[key])
}
</script>
```

## 🔍 查找现有导航组件

### 1. 查找布局组件

可能的文件名：
- `Layout.vue`
- `AppLayout.vue`
- `MainLayout.vue`
- `BasicLayout.vue`

可能的位置：
- `src/layouts/`
- `src/components/layout/`
- `src/components/`

### 2. 查找导航组件

可能的文件名：
- `Navbar.vue`
- `Header.vue`
- `Sidebar.vue`
- `Navigation.vue`
- `Menu.vue`

### 3. 查找App.vue

在 `App.vue` 中通常能找到主布局结构。

## 🎨 图标推荐

从 `@ant-design/icons-vue` 选择合适的图标：

```typescript
import {
  ReadOutlined,        // 阅读图标
  FileTextOutlined,    // 文档图标
  BookOutlined,        // 书籍图标
  FileOutlined,        // 文件图标
  ContainerOutlined,   // 容器图标
  SnippetsOutlined,    // 片段图标
  FormOutlined,        // 表单图标
  ProfileOutlined      // 个人资料图标
} from '@ant-design/icons-vue'
```

推荐：`ReadOutlined` 或 `FileTextOutlined`

## 📱 响应式建议

```vue
<template>
  <div class="navbar">
    <!-- 桌面端导航 -->
    <a-menu v-if="!isMobile" mode="horizontal">
      <a-menu-item key="article">
        <ReadOutlined />
        资讯中心
      </a-menu-item>
    </a-menu>

    <!-- 移动端抽屉导航 -->
    <a-drawer v-else v-model:visible="drawerVisible" placement="left">
      <a-menu mode="inline">
        <a-menu-item key="article" @click="goTo('/article')">
          <ReadOutlined />
          <span>资讯中心</span>
        </a-menu-item>
      </a-menu>
    </a-drawer>
  </div>
</template>

<script setup lang="ts">
import { ref, computed } from 'vue'
import { useRouter } from 'vue-router'

const router = useRouter()
const drawerVisible = ref(false)

// 检测是否移动端
const isMobile = computed(() => {
  return window.innerWidth < 768
})
</script>
```

## 🌟 完整示例

假设你的导航栏在 `src/components/Navbar.vue`：

```vue
<template>
  <div class="navbar">
    <div class="navbar-container">
      <!-- Logo -->
      <div class="navbar-logo" @click="goTo('/')">
        服装设计平台
      </div>

      <!-- 导航菜单 -->
      <a-menu
        v-model:selectedKeys="selectedKeys"
        mode="horizontal"
        class="navbar-menu"
      >
        <a-menu-item key="home" @click="goTo('/')">
          <HomeOutlined />
          <span>首页</span>
        </a-menu-item>

        <a-menu-item key="pattern" @click="goTo('/patternGeneration')">
          <AppstoreOutlined />
          <span>智能创作</span>
        </a-menu-item>

        <!-- ✨ 新增：文章资讯 ✨ -->
        <a-menu-item key="article" @click="goTo('/article')">
          <ReadOutlined />
          <span>资讯中心</span>
        </a-menu-item>

        <a-menu-item key="ai" @click="goTo('/ai')">
          <RobotOutlined />
          <span>AI问答</span>
        </a-menu-item>

        <a-menu-item key="myIdea" @click="goTo('/my_idea')">
          <BulbOutlined />
          <span>我的创意</span>
        </a-menu-item>
      </a-menu>

      <!-- 用户操作 -->
      <div class="navbar-actions">
        <a-button v-if="!loginUser" type="primary" @click="goTo('/user/login')">
          登录
        </a-button>
        <a-dropdown v-else>
          <a-avatar :src="loginUser.userAvatar" />
          <template #overlay>
            <a-menu>
              <a-menu-item @click="handleLogout">退出登录</a-menu-item>
            </a-menu>
          </template>
        </a-dropdown>
      </div>
    </div>
  </div>
</template>

<script setup lang="ts">
import { ref, computed, watch } from 'vue'
import { useRouter, useRoute } from 'vue-router'
import { useLoginUserStore } from '@/stores/useLoginUserStore'
import {
  HomeOutlined,
  AppstoreOutlined,
  ReadOutlined,
  RobotOutlined,
  BulbOutlined
} from '@ant-design/icons-vue'

const router = useRouter()
const route = useRoute()
const loginUserStore = useLoginUserStore()

const loginUser = computed(() => loginUserStore.loginUser)
const selectedKeys = ref<string[]>(['home'])

// 根据当前路由更新选中状态
watch(
  () => route.path,
  (path) => {
    if (path === '/') {
      selectedKeys.value = ['home']
    } else if (path.startsWith('/patternGeneration')) {
      selectedKeys.value = ['pattern']
    } else if (path.startsWith('/article')) {
      selectedKeys.value = ['article']
    } else if (path.startsWith('/ai')) {
      selectedKeys.value = ['ai']
    } else if (path.startsWith('/my_idea')) {
      selectedKeys.value = ['myIdea']
    }
  },
  { immediate: true }
)

const goTo = (path: string) => {
  router.push(path)
}

const handleLogout = () => {
  loginUserStore.logout()
  router.push('/user/login')
}
</script>

<style scoped lang="scss">
.navbar {
  background: white;
  box-shadow: 0 2px 8px rgba(0, 0, 0, 0.06);
  position: sticky;
  top: 0;
  z-index: 999;

  .navbar-container {
    max-width: 1400px;
    margin: 0 auto;
    padding: 0 24px;
    display: flex;
    align-items: center;
    justify-content: space-between;
    height: 64px;

    .navbar-logo {
      font-size: 20px;
      font-weight: bold;
      cursor: pointer;
      color: #1890ff;
    }

    .navbar-menu {
      flex: 1;
      margin: 0 40px;
      border-bottom: none;

      :deep(.ant-menu-item) {
        display: inline-flex;
        align-items: center;
        gap: 8px;
      }
    }

    .navbar-actions {
      display: flex;
      align-items: center;
    }
  }
}

@media (max-width: 768px) {
  .navbar-menu {
    display: none;
  }
}
</style>
```

## 🎯 验证集成

集成完成后，测试以下内容：

1. ✅ 点击"资讯中心"可以跳转到 `/article`
2. ✅ 在文章页面时，"资讯中心"菜单项高亮
3. ✅ 在文章详情页时，"资讯中心"菜单项保持高亮
4. ✅ 移动端菜单正常显示和跳转
5. ✅ 图标和文字对齐美观

## 📝 注意事项

1. **路由高亮**：确保使用 `watch` 监听路由变化，更新选中状态
2. **图标导入**：记得从 `@ant-design/icons-vue` 导入图标
3. **响应式**：在移动端可能需要调整菜单显示方式
4. **权限控制**：如果需要，可以添加权限控制（如管理员菜单）
